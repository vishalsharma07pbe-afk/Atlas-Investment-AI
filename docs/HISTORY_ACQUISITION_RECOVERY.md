# History acquisition recovery (R01/R02)

The existing operator history scheduler retains its prior-day-only daily candle policy, verified regular calendar, exact mapping, permission checks, shared provider cooldown, pacing, and ten-request maximum per exchange per pass. No current-session candle or adjusted-series qualification is introduced.

V38 adds nullable target_session and claim_token to the existing ledger without resetting attempts. A newer target can supersede an older successful cooldown when the listing is stale; a same-session success, failure cooldown, or unexpired running lease cannot be bypassed. Legacy successful rows may be refreshed once when stale because their target was not recorded. Legacy running leases expire on their existing schedule. New claims expire after 30 minutes and completion is fenced by a unique claim token. This is not a guarantee of exactly-once HTTP after lease expiry. Successful completion requires a positive write count and a complete validated target-date candle in storage; partial writes are retained, but missing targets are failed and retried on the existing failure cooldown.

Established histories (at least 25 observations, latest within acquisition window) get a short incremental request to catch up before later depth/gap repair. Expansion reservations remain 6/4 in quote-screen mode and 8/2 otherwise; unused slots may be borrowed without increasing request budget. Provider entitlement, 429/retry-after, and raw/adjusted protections remain unchanged. The 30-minute lease is an engineering default, not a provider SLA; current HTTP request timeout is 25 seconds, but body/DB processing is not fully deadline-bound. No local restart or live-provider verification is claimed.

Acceptance: run existing Spring unit and database integration tests, then compare actual latest-session counts and attempt statuses after a controlled restart using the existing local acceptance diagnostics. R10 UI and broader provider, calendar and adjusted-data work remain pending. Product certification remains pending.
