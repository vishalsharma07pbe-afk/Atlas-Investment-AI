# Automatic company evidence

Extends the existing autonomous stock research cycle with cached public company evidence by active registry ISIN. Existing Upstox fundamentals adapter, read-only token, usage rights and entitlement settings are reused; no additional provider or paid AI service is enabled. At most one company report (up to eight existing endpoints) per research pass, with persistent claims, six-hour partial/failure cooldown, 24-hour complete refresh and one-hour provider-wide pause after an unavailable report. No broker holdings or private user data are used. NSE competitor keys use the existing ISIN convention; BSE competitor evidence requires mapping and is not guessed.

Cards display provider-reported ratios vs sector, dated financial statement rows with original units, balance-sheet totals, shareholding periods, corporate actions and peers when returned. Missing fields remain unavailable. Only normalized bounded fields and source paths are cached. Retrieval date is not the period of a financial report or proof of timely disclosure. Evidence older than 24 hours is hidden. This does not independently verify filings, calculate intrinsic value, create price targets, rank stocks by fundamentals, or change recommendation qualification. AI review remains technical-only in this increment. Live acceptance requires the existing authorized provider and actual returned schema; no real account data was inspected for this change.

Enablement is automatic in Compose when existing permissions and token are present. Set ATLAS_AUTOMATIC_COMPANY_RESEARCH_ENABLED=false to disable. No destructive database migration.
