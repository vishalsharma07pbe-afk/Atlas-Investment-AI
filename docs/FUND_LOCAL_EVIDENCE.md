# Authorized local fund evidence

Official pages:
- NSE Indices historical data: https://www.niftyindices.com/reports/historical-data (Total returns Index Values, gross TRI column, not price or net TRI).
- AMFI TER: https://www.amfiindia.com/ter-of-mf-schemes
- AMFI data/disclosure navigation: https://www.amfiindia.com/research-information/amfi-data

No supported automated contract has been verified. This is a local **operator-normalized** input, not an authenticated download or an automatic official data feed. Only use exports for which usage rights are confirmed. Do not enter invented values. Retain original publisher files outside this normalized evidence file. Verify exact Direct Growth AMFI code/ISIN and current benchmark yourself. Historical benchmark changes are not verified.

Set ATLAS_MF_LOCAL_EVIDENCE_ENABLED=true and MARKET_DATA_USAGE_RIGHTS_CONFIRMED=true only if authorized. Put data/fund-evidence/evidence.json in the local repo (do not commit actual licensed files). Compose mounts the folder read-only. On every category dashboard/scheduled refresh, validated data is read automatically. Missing or invalid data is withheld. Existing qualification gates unchanged.

Schema (field definitions, not sample data):
- schema: "MF-LOCAL-TRI-1"
- authorization_attested: true
- indices: array of {benchmark, source_url, series_type, observations}; exact uppercase names from INDEXES in fund_local_evidence.py; source_url fixed NSE historical page, series_type GROSS_TOTAL_RETURN_INDEX. Observations are {date: YYYY-MM-DD, tri: positive numeric value} in strict ascending order, 157–2000 per index, no duplicates.
- schemes: array of {scheme_code: integer, isin_growth, plan: DIRECT, option: GROWTH, benchmark, source_url: AMFI data page, ter_source_url: AMFI TER page, disclosure_date, ter_date, ter_percent: numeric percent, riskometer, riskometer_date}. All dates ISO, no future dates. Maximum 1000 schemes; distinct codes and ISINs. Riskometer enum in code.

Matched comparisons require all 157 exact observed NAV dates in supplied TRI, original anchor digest, same scheme identity, current disclosure <=60 days. TER older than 90 days and Riskometer older than 60 days are separately withheld. One/three-year annualized comparisons, 105 overlapping rolling years, relative return differences and weekly active volatility are descriptive. Segment proxy uses Nifty 100, Midcap 150 and Smallcap 250 TRI; not a fund's actual benchmark. No rating, forward estimate, qualification, or automatic trade.

## Scheduled authorized gross TRI CSV sources

Set `ATLAS_MF_OFFICIAL_TRI_ENABLED=true` only with confirmed rights and a verified direct HTTPS CSV contract on `www.niftyindices.com` or `niftyindices.com`. Put `tri-sources.json` alongside `evidence.json` with `schema` = `NSE-TRI-CSV-1`, `authorization_attested` = true, and `sources` = a list of `{benchmark,url}`. Benchmark must be an exact supported TRI name; URL must be an actual authorized direct CSV URL, not the interactive report page. No default endpoints are guessed. The published historical report distinguishes gross and net TRI; supported CSV headers are `IndexName,Date,Total Returns Index` with optional `Net Total Return Index`. Current publisher CSV transport and exact downloaded schema remain subject to live acceptance. One bounded request per due pass, six-hour per-series refresh, 48-hour cache age and seven-day latest observation checks. No redirects or credentials. Local and downloaded series are not spliced; contradictory overlaps withhold the index. Current fund benchmark mapping still requires exact authorized scheme evidence. No promotion of qualification gates.

## Optional NSE financial filing index discovery

The existing `ATLAS_NSE_FINANCIAL_FILINGS_ENABLED` route continues to accept an authorized archive-link manifest. An additional opt-in `ATLAS_NSE_FINANCIAL_INDEX_ENABLED=true` enables bounded candidate discovery for exact public NSE watch identities when no manifest link exists. The website endpoint `https://www.nseindia.in/api/integrated-filing-results` and response fields are reported in public third-party client documentation (jugaad-data NSELive integrated_filing_financials); this is not an officially documented or live-accepted feed. If denied, incomplete, ambiguous, or structurally different, evidence remains unavailable. No cookies, redirect following, browser emulation, guessed archive URLs or fallback to another venue. The latest quarter must have one unique consolidated iXBRL URL; the existing official archive parser verifies exact ISIN, reporting period, scope and reconciliation. Index response hash and document hash are retained, auto evidence expires after 24 hours and permission revocation hides it. Private holdings may read already-cached public evidence only; no private selection is sent to the exchange. Confirm source access and rights before enabling.

## Publisher monthly factsheet adapter (PPFAS pilot)

Opt in with `ATLAS_MF_OFFICIAL_AMC_ENABLED=true` and confirmed data usage rights. Configure `data/fund-evidence/amc-factsheet-sources.json` with `schema` = `PPFAS-FACTSHEET-1`, `authorization_attested` = true, and `sources` = array of up to two actual public monthly factsheet HTTPS URLs. The published October 2026 layout is visible at https://amc.ppfas.com/downloads/digital-factsheet/2026/october-2026/ . No generated URLs or inferred scheme identity. Bounded scheduled fetch of newest configured month; no redirects. Only Flexi Cap and Large Cap scheme headings and explicitly mapped benchmarks are supported. Exact AMFI Direct Growth code/ISIN plus matching dated NAV in the local AMFI catalog is required. Riskometer and benchmark are publisher-reported; base expense is separate from TER, not a substitute. The HTML parser is fixture-tested against observed table labels; runtime HTML and local AMFI match still require live acceptance. No names are mapped to security ISINs. Full official portfolio spreadsheets and true TER remain separate tasks.

For automatic month rollover, set `discover_latest` = true in the authorized manifest (sources may be empty). The scheduler follows only valid current-month links actually present on https://amc.ppfas.com/downloads/factsheet/ and caches the selected URL for up to 48 hours; a failed index refresh does not reuse stale data. The exact dated NAV reconciliation uses the existing internal Spring/PostgreSQL AMFI outcome-window endpoint, not the unrelated Python manual import catalog. The base expense value is withheld unless the explicit base-expense label is present and both displayed values agree.

The pilot also extracts the observed Flexi Cap nine-category asset allocation table only when labels are explicit, unique, contiguous and total 99.5–100.5%. These are publisher category weights, not exact holdings. An available authorized TRI series may supply a historical matched-date comparison for the current reported benchmark, never a historical mandate or qualification claim.

## Original downloaded gross TRI CSV files

With the existing local evidence permission flags enabled, ATLAS now automatically reads original authorized publisher CSV exports directly from data/fund-evidence/. Use fixed filenames tri-nifty-100-tri.csv, tri-nifty-midcap-150-tri.csv, tri-nifty-smallcap-250-tri.csv (other names follow the exact supported benchmark lowercased with spaces/colons replaced by hyphens, prefixed tri- and suffixed .csv). Download the gross Total Returns Index column from the official report, not the price or net series. No normalized JSON or direct URL is needed for the index itself. Exact index/date identity, at least 157 observations spanning 1092 days and latest observation within seven days remain mandatory. Source hash is retained; operator files are not independently authenticated. Scheme-level TER, riskometer and historical benchmark identity still require their own evidence. Conflicting overlapping series are withheld even if a third source agrees with one of them. No splicing of series or qualification promotion.

## Optional cost-only evidence

Authorized operators can place a normalized ter-components.csv in the same gitignored folder, using the exact header defined by TER_FIELDS in fund_local_evidence.py. This is an ATLAS format, not a claim about AMFI's download schema. Use original published Direct Growth scheme code and ISIN, observation date and the actual published annualized percentage components and total from https://www.amfiindia.com/ter-of-mf-schemes. No guessed values. BER, brokerage, transaction and statutory levies must reconcile to the reported TER within 0.0002 percentage points (conservative rounding assumption). Seven-day freshness; duplicate identities and inconsistent rows rejected. The cost report does not depend on missing benchmark/Riskometer; conflicts with same-date normalized disclosure withhold the TER. Original file hash retained. This is descriptive operator-authenticated input, not independently verified official TER or automatic publisher collection; ranking qualification unchanged.

## Opt-in automatic AMFI website TER collection

ATLAS supports a bounded experimental website JSON collector (OFFICIAL_AMFI_TER scheduler job). Enable ATLAS_MF_AMFI_TER_AUTO_ENABLED only after confirming automated access rights. Use the existing gitignored evidence folder and amfi-ter-crosswalk.json with schema AMFI-TER-WEBSITE-1, authorization_attested true, and schemes containing amc_id, nsdl_scheme_code, scheme_code, isin_growth, plan DIRECT, option GROWTH, verified_date. Establish mapping using publisher/registration documents, never fund names. Crosswalk expires after 90 days. Fixed AMFI host, one AMC per 15 minutes at most, each AMC no more than daily on success, persistent 6-hour global failure cooldown and Retry-After. Validates complete page, identity, dates, expense component sum; no inferred total or name matching. Direct endpoint was described by independent developers at https://github.com/satwikbasu/indian-market-data-endpoints/blob/main/endpoints/amfi-ter-api.md; live payload could not be verified in development. Thus disabled by default, no live availability promise. No independent identity certification or ranking gate promotion. Crosswalk-free official collection still requires an authenticated NSDL-to-AMFI identity source.\n
A complete zero-row response is treated as no current matches, not a transport failure. During the first seven days of a month, an even-day retry after no matches may use the prior month within the same request budget. A successful response supersedes its own monthly scope only; a still-current adjacent-month observation retains its original date and hash until newer evidence arrives or seven-day freshness expires. Invalid cached rows are isolated. This does not validate the live website contract.
