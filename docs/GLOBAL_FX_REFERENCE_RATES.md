# Global currency reference research

Enable ATLAS_GLOBAL_FX_ENABLED=true and MARKET_DATA_USAGE_RIGHTS_CONFIRMED=true only after reviewing applicable terms. Recreate the intelligence service. No key or broker account required. Existing durable coordinator fetches the official ECB EXR daily reference series on a six-hour cadence (with existing failure backoff). Data cached locally; overview reads only saved evidence.

Source: European Central Bank, https://data.ecb.europa.eu/help/api/data-examples and https://data.ecb.europa.eu/data/datasets/EXR/EXR.D.INR.EUR.SP00.A. Usage/disclaimer: https://www.ecb.europa.eu/services/using-our-site/disclaimer/html/index.en.html. ECB reference rates are informational only. ATLAS-derived cross rates and percentage changes are modifications, explicitly labeled. No external AI payload. 90-calendar-day request, fixed currency allowlist, 24-hour capture and five-calendar-day observation freshness; paired legs must have same latest date. Changes over 1/5/20 previous available observations with bounded gaps, no interpolation or session verification. No commodity, equity index, rate or market-impact inference. Runtime connectivity and source payload verification required.
