# Authorized local deal reports

Place a normalized public-report CSV named `deals.csv` in this directory (use atomic rename). See `../templates/deal-reports.csv` for headers. Enable `ATLAS_DEAL_REPORTS_ENABLED=true` and `MARKET_DATA_USAGE_RIGHTS_CONFIRMED=true` only if permitted to use the source. Restart intelligence with the updated Compose configuration. The durable coordinator reads it automatically at the existing research cadence; no exchange scraping or external requests. Supply an authorized report or licensed export, map exact exchange/symbol/ISIN before import, and retain a report identifier in source_report. ISO trade dates, NSE/BSE, BULK/BLOCK, BUY/SELL, positive integer shares and decimal INR price without separators. Replace with the complete intended rolling file, not incremental fragments. Dates limited to 120 days, displayed recent evidence to 30 days. Identical records are rejected, not double counted. Last successful capture can remain visible for up to 48 hours after failure. File is not tracked in Git. No holdings or account information. Source acquisition and independent verification are not implemented.
